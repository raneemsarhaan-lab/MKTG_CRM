How it works

  • Task column. One column says which task a row is (a link, or a task's name). Rows with a task get a ↗ marker and live fields; other rows are plain rows.
  • Task fields (purple headings): Stage, Assignee, Owner, Due date, Priority, Platform, Content type, Theme, Pillar, the four links, and the team's own Content columns. They show and edit like the Content sheet; on rows without a task they stay empty.
  • Regular columns (grey headings): normal spreadsheet cells with all the formatting tools.
  • Add from ＋ at the end of the headings, or ⚙ Fields → switch a field on. Use an existing column for a field (today's mapping) from the same place: “Show in: column F”.
  • Hide a field by switching it off: the column goes, the task keeps its value.
  • Your own words. ⚙ Fields → Stage → Values: write the words this sheet uses for each stage (“editing in progress” → D-In Progress). Typing or pasting them sets the stage; cells can show your words or the board's. Turning a column like “Status (our words)” into Stage asks you to match each value once.

Content and Video sheets

  • Same drawer, same field columns and regular columns (today's “+ Column” custom columns become regular or field columns).
  • Their rows are filled from the board (Content pipeline / Video), grouped by Theme › Pillar; that's shown at the top of the drawer and can't be switched off there.
  • Columns, Mine, Show archived and Paste plan stay; Columns becomes ⚙ Fields.
  • Nothing about the board changes; this is how sheets show and edit task fields.
