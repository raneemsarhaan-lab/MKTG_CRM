The Video sheet, in the Content sheet's look

The four changes you picked. Each video becomes a tinted band with its clip count, the way Content shows "Strategy · 9", and gets its own "+ Clip" row. Type is a coloured pill. Every heading has an icon. The Editing / Copy / Full switch and the Board / Sheet switch are gone, so the toolbar is Content's: Columns, + Column, Mine, Show dropped (Content's "Show archived") and Paste clips.

Columns you don't want are hidden from Columns (the Fields drawer), as on Content. Everyone starts from the full set; the old per-person Editing / Copy views go away.

What changes, and what stays

1 · Videos as bands
  • Tinted band like Content's: ▼ name · clip count.
  • The video's stage shows as a pill on the band; ↗ opens its task (editor and files are set there).
  • ▼ folds the clips; each band ends with "+ Clip".
2 · Type as pills
  • Reel, Short, Video… in the same coloured pills as Post, Article, Report.
  • Clicking still opens the type menu.
3 · Icons on every heading
  • # for the clip number, A for Source and File name, ◷ for In, Out and Length (marked in yellow here).
  • Title stays plain, as on Content.
4 · Toolbar like Content's
  • Editing / Copy / Full removed: one column set, trimmed in Columns.
  • Board / Sheet removed from the Sheets page. On the Board page the switch stays, or you couldn't get back to the board.
  • Summary line reads "Video plan · videos · clips · time · …" like "Content plan · 18 pieces".
