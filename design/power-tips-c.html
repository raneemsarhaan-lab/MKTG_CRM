Drag the selection's border

  • Point at the edge of the selection: the pointer turns into the move arrows ✥. Drag, and a dashed outline shows where the block lands, with its address.
  • Drop: the cells move with their formats, comments, data validation and any merge inside the block. One undo step.
  • Over cells that hold data, Excel's question first: There's already data here. Do you want to replace it?
  • A move that would split a merge or a table is refused with a note. Esc while dragging cancels.
  • Mouse only; phones keep Cut and Paste.

The board's sheets

Their rows are tasks and their columns are task fields, so moving cells isn't offered there; Cut and Paste still work.

Alt+drag to another sheet

  • Start a border drag, hold Alt and move over a sheet tab: that sheet opens under the pointer, as in Excel.
  • Drop where it should go; the block leaves this sheet. Ctrl+Alt leaves a copy here instead.
  • Undo works on each sheet: the move is a step on both.
  • Ctrl+drag a tab still duplicates the sheet (tip 112).

Locking cells has no effect until you protect the sheet (the sheet tab's menu › Protect sheet). Every cell starts locked; untick Locked for the cells people should still fill in.

Format Cells › Protection

  • Excel's tab: Locked (on for every cell until you untick it), and Hidden, greyed: it hides formulas, which these sheets don't have.
  • Unlocked cells keep their look; nothing changes until the sheet is protected.
  • Kept with the cell's format, so Format Painter and Paste Special › Formats carry it.

File › Print (Ctrl+P)

  • Prints the sheet's used range, or the selection, with the cells' looks (fonts, fills, borders, number formats, Center Across).
  • Excel's page options: orientation, Fit All Columns on One Page, Rows to repeat at top (the header row on every page), gridlines, row and column headings.
  • The preview shows the pages; Print opens the browser's print window, where Save as PDF makes the PDF.
  • Hidden rows, collapsed groups and filtered-out rows don't print, as in Excel.

The board's sheets

File › Print there too, with the same options, printing what's on screen (the board's own columns).
