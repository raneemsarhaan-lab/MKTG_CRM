Space sheets

One kind of sheet, used as the Sheet view of every Space, every Space › Brand folder and every brand page. It replaced the separate Content and Video sheets and the Sheets section. A row is a line of the plan; linking it to a task makes the row and the task one thing.

On a brand's page

Sheets by SpaceContent 12Design 0Video 5Planning 0All tasks 61
  • Each Space is on the strip with the number of the brand's rows on its sheet. Choosing one opens that Space's sheet for the brand, on the same page, fully editable.
  • All tasks lists the brand's tasks from every Space together, with a Space column.
  • The page opens on the Space last used for that brand, or the first Space that has rows.

There is no Sheets section in the sidebar. An old Sheets address, and the link in a sheet-comment notification, lead to the page that owns the sheet, on the same tab and cell. Each sheet sits in a workbook, so blank tabs can still be added beside it.

2 · Themes, pillars, rows

▾ Theme a group row across the sheet; it is a project ▾ Pillar a sub-group of its theme Row plain, or linked to a task Child row one level under a row + Row Row a row with no pillar sits under the theme + Row

Adding

  • Theme: "+ Theme" on the toolbar, or Insert theme above / below in a theme's menu. Pick an existing project or make one (name, owner, frequency, audience). Admins and superusers.
  • Pillar: "+ Pillar" in a theme's menu. Admins, superusers and the theme's owner.
  • Row: "+ Row" at the end of each theme or pillar (it carries the Space's own words, such as "+ New clip"); type, and Enter adds it and starts the next. Anyone with access to the Space.
  • Child row: Add child row in a row's menu, or Tab on a row's number. One level only.

Moving and removing

  • Drag a row by its number onto a theme or pillar. A linked row's task changes its theme or pillar to match.
  • Themes and pillars are reordered by dragging; this changes the sheet, not the projects.
  • Removing a theme or pillar asks where its rows go. A removed theme leaves this sheet only; the project stays.
  • The same project can be a theme on several Spaces' sheets; each sheet has its own rows under it.

3 · Plain rows

  • A planning line, not a task: no SLA, no approvals, no card on a board.
  • It holds a title, a date and its own value in every column.
  • Its Status is a label in the Space's stage names. It triggers no stage rules.
  • Anyone with access to the Space can edit plain rows.
  • Paste plan only ever creates plain rows, on the sheet it is pasted into. A pasted task link no longer links or changes a task.

4 · Linked rows and Make task

The Task column shows Make task on a plain row. It asks for the destination Space, then either creates a task there or connects the row to a task that is already there.

A new task

  • Starts where that Space starts (Design and Video: Ready For Design), on its board if it has one.
  • Takes the Space's default type, assignee and priority, the brand of the folder, and the theme and pillar of the row's groups.
  • The row's date becomes the publishing date; values in task-field columns go to the task when its type has that field.
  • Only people who may create in that Space can make it.

An existing task

  • It must be in the chosen Space and not already on this sheet.
  • Where both have a value, the task's value wins; the row fills only what the task lacks.
  • The task joins the row's theme and pillar.
  • Once linked, every task-field column is the task's field: an edit in the sheet, the task panel or a board shows everywhere. Task permissions, required fields and stage rules apply to those cells.
  • The Task cell shows the task's name as a link, its Space and its stage.
  • Unlink keeps the row with its last values as plain text. The task carries on in its Space.
  • The Content Space's sheet still gives a new task in one of its themes a row by itself, so work started on a board appears in the plan. Other Spaces' sheets hold only what is put on them.

5 · Child rows

  • Any row can have child rows, one level deep.
  • Linking a child row whose parent is linked makes a subtask of the parent's task, in the same Space.
  • Under a video's row it makes a clip: a Reel on the Video board at Ready For Design, with the Video Space's default assignee.
  • A child row can't be linked while its parent is plain. The Task cell says why.

6 · Columns

Task field

Type, Status, Assignee, the link columns, Pillar, Date, and every field of the field library (Caption, Channels, TOV…). A linked row shows and saves the task's value. A plain row holds its own until it is linked.

Sheet only

A column the team adds with a kind of its own (text, number, date, link, person, choice, checkbox, related task). It stays on the row, stays when the row is linked, and never touches the task.

  • + Column asks which: a task field (the sheet's hidden ones and the field library), or a new sheet-only column.
  • A library field shows by itself while a task type in use carries it. Any other can be switched on.
  • The Fields button opens the drawer: show or hide, move, rename, and Group rows by. All of it is per sheet, so renaming a column on one Space's sheet changes nothing in the library or on another sheet.
  • A Space's settings choose its default sheet columns: what the sheet shows until someone shows or hides a column there.
  • A task-field cell is hatched where the row's task type doesn't use the field, or its brand has switched it off.
  • Each Space's sheet has its own columns. The layout is shared by the team; the drawer shows who changed it last.

7 · Status and stages

To Do→C-In Progress→C-Review→C-Check→Ready For Design→D-In Progress→D-Check→F-Check→Ready to Publish→Scheduled→Published
  • On a linked row, change Status from the menu or by typing a stage in the Space's names. Whoever holds the current stage may move it; admins and superusers can move any task.
  • Review stages (shaded) belong to a role, or to the owner or approver the Space's settings name for that stage.
  • Required fields are checked by the task's home Space. Content asks for Caption and TOV before C-Review; Video doesn't ask a clip for them. A stage before the Space's start is never asked for.
  • While a content row's linked Design or Video tasks haven't passed D-Check, its Status follows them.
  • Moving a piece to Published asks for its Published link.

8 · Editing rules

Who edits what

  • Plain rows: anyone with access to the Space.
  • Task-field cells of a linked row: the task's owner, its assignee, admins and superusers. Anyone else sees "read only".
  • Sheet-only columns, formatting and comments: any member, on a live row.
  • Unlinking and Make task: people who may link or create in that Space.

How

  • Click and type replaces; Enter, F2 or double-click edits. Undo and redo follow the same rules.
  • Paste fills cells and counts what it skipped. A table pasted on a theme, pillar or "+ Row" opens Paste plan.
  • The toolbar has two buttons: + Column and + Theme. Paste plan, Only my rows and Show archived are in the Data menu.
  • Bulk bar (2+ linked rows): Stage, Assignee, Type, Pillar, Date, Archive. One Undo reverses it.

9 · Formatting and comments

  • Fills, fonts, number formats and colour rules are kept per row and column, so they follow the row through sorting, filtering and archiving.
  • Sort and filter work inside each theme and never change a board's order.
  • Cell comments are threads with @mentions, resolve and reopen. Their notifications open the sheet on its Space or brand page, at the cell.

10 · Shared or private

Shared by everyone

Rows, themes and their order; each sheet's columns, names and widths; sheet-only values; task fields; row heights; sort, filter and grouping; formatting, colour rules and comments.

Per person or device

Only my rows (resets each visit), Show archived (remembered on the device), collapsed themes, and which Space a brand's sheet last opened on.

11 · What changed from the old sheets

BeforeNow
Content sheetThe Content Space's sheet. Its themes, pillars, rows, columns, formatting and comments carried over.
Video sheetThe Video Space's sheet. Each video became a linked row, its clips linked child rows. A video with no project sits under "Videos · brand".
Clip detail columnsRemoved (#, Source, File name, In, Out, Length, File). Their values were exported first to clip-details.csv, kept in Settings › Diagnostics.
Bulk linkingRemoved. Rows are linked one at a time with Make task.
Sheets sectionRemoved. Old addresses lead to the page that owns the sheet. Folders of blank sheets made there are removed; what they held is kept as CSV files in Settings › Diagnostics.
Design, Planning and new SpacesEach has its own sheet, empty until rows are added.

12 · Open points

Decisions still needed:

A brand's rows in one grid. The brand page shows one Space's sheet at a time, because each Space's sheet has its own columns, formatting and comments. One merged grid would need shared columns across Spaces.
"Videos · brand" themes. Created for videos that had no project. Keep them, or move those videos into real projects?
Existing tasks of other Spaces. Design and Planning tasks made before the change aren't rows on their Space's sheet. They can be added one at a time with Make task › an existing task.
"Waiting for Caption". When a linked row is held at D-Check because a required field is empty, the cards and the sheet show the red "missing" words, but the row doesn't yet say it is waiting.
Linked-row permissions. The Status menu offers stages by the row's own holder, while the server checks the linked tasks' holders, so typing a stage can succeed where the menu offered nothing.
