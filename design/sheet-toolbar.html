Sheet toolbar, spreadsheet style

Spec 018 design. The sheet header gets the layout people know from Google Sheets: a menu bar (File, Edit, View, Insert, Format, Data, Help), one rounded toolbar strip, and a name box with the cell's content. Every tool we have today stays; this page shows where each one goes. Click the menus and the ▾ buttons; switch to a narrow window to see the ⋮ overflow.

What changes

Menu bar. File, Edit, View, Insert, Format, Data and Help hold every command, including the ones in today's ▾ menus (Clear, Fill, Freeze, Hide, Sort & Filter, Conditional formatting, Format as Table, Cell styles).

One toolbar strip. The everyday tools in the familiar order: find, undo, redo, Format Painter, currency, %, decimals, number formats, font, size − +, bold, italic, strikethrough, text colour, fill, borders, merge, align, vertical align, wrap, rotate, then comment and filter. Undo and redo move into the strip. What doesn't fit goes under ⋮.

Name box and cell bar. The selection's name (or "3 areas") on the left, the active cell's content beside it, and the cell count on the right. Typing in the cell bar edits the active cell; Enter saves it. Typing a cell name like D20 in the name box jumps there.

Same everywhere. Blank sheets and the Content and Video sheets get the same header; tools a linked sheet can't use stay disabled with their reason, as now. Phones keep the Format sheet at the bottom.
