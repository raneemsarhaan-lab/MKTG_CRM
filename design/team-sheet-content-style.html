Team sheets, Content-sheet style

A team sheet (here: TSC Calendar) looks and works like the Content sheet. Column names are the headings, task rows have the same pills, people and links, and rows are grouped under coloured theme and pillar bands. It is still your sheet: regular columns, formatting, comments and undo stay.

Headings

Column names, not letters

The sheet’s first row becomes the headings (Topic / Title, Date, Status…), with the field icon, as on the Content sheet. Letters (A, B, C) show only in the name box and formulas-free references such as “B4”.

Rows

Theme and pillar bands

Rows are grouped by the task’s theme › pillar by default, in the Content sheet’s colours, with counts and collapse. Rows with no task yet sit under “Not created yet”. Group by can switch to Stage, Assignee, Type, a column, or None (your own order).

Cells

Identical cells

Status pills in your words, people with avatars, coloured type pills, “+ link” / site name, underlined “Open task”, and ＋ Create task on rows without a task: the same components as the Content sheet.

Toolbar

The Content sheet’s bar

Columns · + Column · Mine · Show done · Add tasks… · Paste plan, and a summary line (rows, tasks, not created yet, published). The spreadsheet tools (format strip, menus, comments, undo) stay.

Stays a sheet

Still your spreadsheet

  • Regular columns are free text, formatting and merges work.
  • Typing in a regular column never touches the board.
  • “+ Row” adds a row in that group.
Question

Grouping by default

Content-style needs a grouping by default. I suggest Theme › Pillar for sheets with tasks, and None (your row order) for sheets with no tasks linked. You can change it per sheet.
