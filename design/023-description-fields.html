Where the sections come from

  • The task's type decides them: a Post gets Caption and Channels, a Report gets Budget. Their order is the type's field order on the Task types page.
  • Description is always last and stays free text with bold, lists, tables, mentions and checklists, as today.
  • A field the type has but that's empty can be hidden from the description until needed, then brought back with /. A required field can't be hidden.

One value, everywhere

The Caption typed here is the same Caption in the sheet, on cards and under the Fields button. Editing it in the sheet updates this section.

Required, and how a move is refused

  • The section's tag says which stage needs it ("Needed by C-Review") and turns red while it's empty.
  • Moving the task past that stage, from anywhere, is refused with "Caption is required before C-Review". The panel scrolls to the section and outlines it.

Editing rules

  • A section can't be deleted by accident. Backspace at its start doesn't merge it into the one above; selecting across sections and deleting empties them, with Undo.
  • Caption is plain text with line breaks and emoji, so it pastes cleanly into Instagram or LinkedIn. The count is characters, for platform limits.
  • Choice and date fields show a compact picker inside their section instead of text.
  • Changing the type hides the sections the new type doesn't have. Their values are kept and come back if the type changes back.
  • The history shows "Samaa changed Caption", as for any field.
