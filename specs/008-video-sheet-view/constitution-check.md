# Constitution Check: spec 008 (for the PR description)

Governance requires a Constitution Check note on PRs that add views, components or state shape. This is the note for the video sheet.

| Principle | How this PR meets it |
|---|---|
| **§I Design System Fidelity** | Colours come from `SHEET_UI` (new, `src/lib/tokens.ts`), `STAGE_COLORS`, `COLORS`, `BRIEF_UI` and `ATTACH_UI`. They are mirrored as `--sheet-*` variables in `globals.css`, and the `.fx-sheet-*` block uses variables only. The lab's `tokens-only` check finds no hex or `rgba()` literal in `src/components/sheet/`. |
| **§II Workflow Pipeline Integrity** | No stage is added, removed, renamed or reordered. The video names ("Editing", "Final Cut"…) are message strings shown in the sheet only. Drop is a flag, not a stage. The move rule moved into `src/lib/stage-moves.ts` unchanged: the lab checks it against the old inline rule in over 5,000 combinations. Restore moves `stage_date` so the SLA, still computed on render, reads as it did. |
| **§III Role-Based Feature Access** | Edit, upload, drop and move controls render only when the member may use them, and every new action checks again on the server. **Sign-off requested: the clip exception.** `user`-level members may add clips through `addClips` only. It makes Reel subtasks of a Video, owned by the member adding them (so they are "own tasks"). `createTask`, `createSubtask` and the New task form are unchanged for `user` (FR-036, checked in the running app). **Reviewers, please approve this exception.** |
| **§IV Design-Driven Development** | `design/video-sheet.html` was committed before any UI work (T001) and published for approval. **Sign-off requested:** like specs 005 and 007, it is plain, readable HTML rather than the bundled prototype format. |
| **§V Cultural UX** | Every new string is in the `sheet` namespace in English and Arabic; the lab's `messages-parity` check confirms the keys match and nothing is left untranslated. The grid, summary, paste preview and menus lay out right to left, and times stay in Western digits. **Native review requested** for the proposed Arabic video stage names (research R4). Status changes go through the board's own move, so the celebration fires under the same rule (own stage, forward), checked in the running app. |
| **§VI State Architecture** | No new store state: the view and video are in the URL, cell editing is local. The new unions (`BoardView`, `SheetColumnSet`, `SheetColumn`) and `ClipDetails` are in `src/types/index.ts`. The column set and Show dropped are per-device `localStorage` preferences, which **constitution 2.1.0** allows (amended with this plan, analysis finding C1). **Reviewers, please approve the 2.1.0 amendment.** |
| **Tech Stack** | No new dependency. A grid library was considered and rejected (research R10). The lab reuses esbuild, Playwright and axe-core. |
| **Schema** | `task_clips` (new), `tasks.published_url`, `tasks.dropped_at`: all new or nullable, applied with `prisma db push`, no backfill. |
